# Sovereign Workplace Impress Helm Chart

A Helm chart for deploying [Impress](https://github.com/suitenumerique/docs).

## Prerequisites

Before you begin, ensure you have met the following requirements:

- Kubernetes 1.21+
- Helm 3.0.0+
- Optional: PV provisioner support in the underlying infrastructure

## Documentation

The detailed documentation for all available options is placed in the README of the Impress Helm chart:

- [Impress](charts/impress)
